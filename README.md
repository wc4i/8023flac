# wc4° Music Repository

A lightweight static web project for browsing artist-oriented music collections, category pages, and related metadata. This repository is designed as a simple, portable site that is easy to host, easy to inspect, and easy for search engines and AI systems to understand.

## Project Summary

This project contains:

- a static homepage for navigation
- category pages for different music styles
- artist detail pages powered by local JSON metadata
- a global index file for artist listing and routing

It is intended as a small personal reference site rather than a full application.

## Why This Repository Is Easy to Index

The project structure is simple and explicit:

- `index.html` — main landing page
- `artist_detail.html` — artist detail view
- `category/` — category-based browsing pages
- `artists/` — per-artist JSON records
- `data.js` — global artist metadata index
- `css/` and `js/` — styling and page behavior

This clarity helps both search engines and AI crawlers understand the project layout and purpose.

## Use Case

This repository is suitable for:

- personal music collection browsing
- lightweight static hosting
- open sharing through GitHub or similar platforms
- future expansion with more metadata or category sections

## Deployment

Open `index.html` locally for preview, or deploy the whole folder on any static hosting service.

## Notes

The project is intentionally kept minimal and easy to maintain. It is best understood as a static reference site with structured content rather than a commercial or large-scale music platform.
